# Solicitação de Análise de Feedbacks de Clientes

## Objetivo
Quero que a IA analise os feedbacks das respostas dos clientes para identificar os sentimentos e as sensações expressas pelos clientes.

## Finalidade do Resultado
O resultado será utilizado pela área de marketing para apoiar ações de melhoria no fornecimento dos produtos.

## Entregáveis Esperados
A entrega deve conter:

- Resumo detalhado das análises realizadas;
- Identificação dos principais sentimentos e sensações dos clientes;
- Insights relevantes para tomada de decisão;
- Tabela consolidada com os resultados da análise.

## Critério de Sucesso
O resultado será considerado satisfatório se apresentar uma base sólida para uma tomada de decisão eficiente e orientada por dados.
# Contexto

Estou trabalhando com feedbacks de clientes bancários relacionados a CDB, CDI e Títulos Públicos.

# Dados Disponíveis

A base de dados contém informações sobre:

- Experiência anterior com investimentos;
- Faixa de renda;
- Dificuldade percebida;
- Desconfiança relatada pelos clientes.

# Critérios de Análise

A IA deve analisar e classificar os feedbacks considerando:

1. Nível de experiência do cliente com investimentos;
2. Sentimento identificado no feedback;
3. Faixa de renda informada.

# Cuidados e Restrições

- Utilizar apenas os dados fornecidos na base.
- Não inventar números, causas, hipóteses ou conclusões.
- Não expor dados pessoais, confidenciais ou sensíveis.
- Quando houver informações insuficientes, indicar explicitamente a limitação encontrada.
- Utilizar linguagem simples, objetiva e voltada para a tomada de decisão.

# Resultado Esperado

A análise deve apresentar:

- Resumo executivo dos principais achados;
- Classificação dos feedbacks por experiência, sentimento e faixa de renda;
- Principais dificuldades e pontos de desconfiança identificados nos relatos;
- Evidências encontradas nos feedbacks que sustentem as conclusões;
- Tabela consolidada com os resultados da classificação e análise.

# Critério de Qualidade

O resultado será considerado adequado se:

- Estiver fundamentado exclusivamente nos dados fornecidos;
- Apresentar conclusões rastreáveis aos feedbacks analisados;
- Evidenciar limitações quando existirem lacunas de informação;
- Apoiar a área de marketing na definição de ações de melhoria dos produtos e da comunicação com os clientes.
# Objetivo da Análise

Atue como um consultor de negócios de um banco.

Sua tarefa é analisar os comentários dos clientes sobre suas experiências e sensações relacionadas a investimentos em ativos de renda fixa e títulos públicos emitidos pelo banco, com o objetivo de identificar sentimentos associados aos produtos e gerar insumos para estratégias de melhoria e otimização da oferta de produtos para cada perfil de cliente.

# Contexto

O objetivo da análise é transformar os comentários dos clientes em informações acionáveis, permitindo:

- Relacionar percepções e sentimentos aos produtos citados;
- Identificar quais produtos geram maior confiança, dúvidas ou dificuldades;
- Apoiar a recomendação de produtos mais adequados para cada perfil de cliente;
- Auxiliar a equipe de consultoria na forma de abordar temas relacionados aos produtos;
- Melhorar a comunicação e a experiência do cliente com investimentos de renda fixa.

# Dados Disponíveis

Serão fornecidos os seguintes campos:

- Data do feedback;
- Canal de atendimento;
- Texto do feedback;
- Produto citado;
- Nota de satisfação (escala de 1 a 5).

# Instruções de Análise

A IA deve:

1. Classificar cada feedback por:
   - Tema;
   - Sentimento;
   - Nível de urgência;
   - Produto citado.

2. Identificar:
   - Principais padrões observados;
   - Problemas recorrentes;
   - Elogios mais frequentes;
   - Oportunidades de melhoria.

3. Apontar evidências encontradas diretamente nos comentários analisados.

4. Sugerir ações práticas para orientar:
   - A equipe de consultoria;
   - A comunicação com os clientes;
   - A adequação entre perfil do cliente e produto ofertado.

- Estiver fundamentada nos comentários fornecidos;
